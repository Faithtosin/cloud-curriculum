# Cloud Curriculum

An Astro Starlight site: a free, beginner-friendly path to becoming a cloud engineer. Content is adapted from [Learn to Cloud](https://learntocloud.guide) under CC BY 4.0.

## Commands

- `npm run dev`: local dev server (http://localhost:4321/cloud-curriculum/)
- `npm run build`: production build into `dist/`. Run it after every content change; it must pass.

## Content rules

- **Audience: complete beginners.** Use plain language and explain each acronym the first time it appears.
- **AWS first.** Every cloud example, service and docs link targets AWS. GCP can appear only as a short optional aside. **No Azure.**
- Link to official AWS docs (docs.aws.amazon.com / aws.amazon.com). Don't make up URLs.
- Wherever a step costs money, mention cost: the Free Tier, budget alerts and tearing resources down.
- Pages live in `src/content/docs/phaseN/`. The sidebar is autogenerated from these folders (see `astro.config.mjs`).
- Write internal links root-relative, e.g. `[Phase 1](/phase1/)`. `src/plugins/rehype-base-links.mjs` adds the GitHub Pages base path at build time. Don't hardcode `/cloud-curriculum/`.

## Attribution (must keep)

- Keep the footer credit in `src/components/Footer.astro` and the `/credits/` page (`src/content/docs/credits.md`).
- Whenever you make a significant change, add it to the "Changes made" list on the credits page.

## Hosting

GitHub Pages at https://faithtosin.github.io/cloud-curriculum/, deployed by `.github/workflows/deploy.yml` on every push to `main`. The `site` and `base` values in `astro.config.mjs` must match that URL.
